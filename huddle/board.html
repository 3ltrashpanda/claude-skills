How this board works
  • The page is sorted by who has the ball. Your move is everything only you can do: answers, checks, approvals, and cards to line up. Claude's move is work Claude has or is about to start. Done & parked is out of the way.
  • Each card shows its lane as a chip: Reported → Triaged → Up next → Approved → In progress → In testing → Done. Claude triages what you report; you line cards up (Up next) and clear them to build (Approved); Claude builds and tests.
  • A claim badge on an In-progress card shows when Claude last touched it. While Claude is on a card you can leave comments but not move it. If the badge goes stale you can take the card back.
  • When you answer something, the card says Sent, Claude hasn't read this yet until Claude's next session reads it. You can undo for a few seconds.
  • Ideas start in Reviewing. Each relevant agent adds a verdict (yes / maybe / no), a size (S / M / L) and a reason. You then approve, park, reject or ask.
  • The page only changes while a Claude session is running. Anything you type saves immediately and Claude reads it at the start of its next session.
