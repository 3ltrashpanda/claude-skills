How this board works
  • Work moves Reported → Up next → In progress → In testing → Done. Claude moves cards as agents start, merge and verify work.
  • Issues you add land in Reported. Claude triages them into Up next with an owner.
  • Ideas you or an agent add start in Reviewing. Each relevant agent adds a verdict (yes / maybe / no), a size (S / M / L) and a reason.
  • You then Approve (it becomes a card in Up next), Reject (kept with your reason), or Ask a question back to the team.
  • Anything you type here is saved for everyone with this page, and Claude reads it at the start of each work session.
